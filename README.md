# Hood Secrets — YouTube Companion Pages

Public static pages for **Hood Secrets**, a channel explaining everyday automotive questions and car history.

[Watch the channel](https://www.youtube.com/@ankylab?sub_confirmation=1)

## Contents

- `index.html` — short introduction with a link to the channel
- `privacy.html` — privacy-policy page

## Run locally

Open `index.html` in any modern browser, or serve the folder as static files:

```bash
python -m http.server 8000
```

## Scope

Despite this repository's historical name, it contains **public-facing static pages**, not the source code for the full video-production or publishing automation workflow. The automation pipeline is not documented or shipped in this repository.
